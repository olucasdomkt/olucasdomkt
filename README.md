### O que está aberto

- **[Review IA](https://github.com/olucasdomkt/reviews-de-ia):** ferramentas de IA usadas por pelo menos duas semanas e medidas, com veredito e o script para você medir no seu uso.
- **[Skills abertas](https://github.com/olucasdomkt/skills-abertas):** skills do Claude Code em português, cada uma nascida de um erro real.
- **[Ferramentas](https://github.com/olucasdomkt/ferramentas-claude-code):** três scripts para rodar várias sessões do Claude Code no mesmo Mac.
- **[MCP hub](https://github.com/olucasdomkt/claude-code-mcp-hub):** cada servidor MCP roda uma vez só, para todas as sessões do Claude Code.
- **[Outbox](https://github.com/olucasdomkt/agent-outbox):** fila de aprovação para tudo o que os agentes querem mandar (WhatsApp, e-mail, Discord), com um linter que barra vazamento de segredo. `Node + SQLite · MIT`

### Stack
